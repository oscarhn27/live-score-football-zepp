# Football live score — Help and documentation

*Read this in other languages:* **🇪🇸 [Español](docs/es/README.md)**

Welcome to the public documentation repository for **Football live score**, the
football results app for Amazfit / Zepp OS watches.

Here you'll find:

- 📖 [Installation and usage guide](docs/en/INSTALLATION.md) — how to
  install the app, pair it with your phone, and pick your favorite leagues
- ❓ [Frequently asked questions](docs/en/FAQ.md) — common questions about
  matches, leagues, and how the app works
- 🔒 [Privacy](docs/en/PRIVACY.md) — what data the app collects and how
  it's used

## Found a problem or have a suggestion?

Open an [issue](/issues) on this repository and tell us what you need, with
as much detail as possible (what you expected to happen, what actually
happened, and which watch model you're using). There's no required
template — write it however you like.
