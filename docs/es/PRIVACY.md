# Privacidad

Fútbol Live está pensada para pedir el mínimo de datos posible.

## Qué NO recogemos

- No pedimos registro ni cuenta de usuario.
- No accedemos a tus contactos, ubicación exacta, ni a ningún otro dato del
  móvil o del reloj fuera de lo estrictamente necesario para mostrar
  partidos.
- No compartimos ni vendemos datos a terceros.

## Qué sí recogemos

Para entender qué ligas y funciones se usan más (y así mejorar la app),
guardamos de forma anónima:

- Qué tipo de consulta se hizo (ej. partidos en directo, próximos, eventos
  de un partido) y de qué competición.
- Un país aproximado, deducido automáticamente de tu conexión a internet
  (no de datos de ubicación del dispositivo).
- La fecha y hora de la consulta.

Estos datos **no incluyen ningún identificador personal**: no se guarda tu
nombre, ni una cuenta, ni un identificador de dispositivo que permita
reconocerte entre visitas. Solo se usan de forma agregada, para saber por
ejemplo "cuántas consultas se hicieron esta semana a LaLiga", no para seguir
la actividad de una persona en concreto.

## ¿Cuánto se conserva?

Estos registros se eliminan automáticamente pasado un tiempo (por defecto,
un año).
